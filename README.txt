MEITETSU Operation Web v4.0

追加機能:
- 列車番号検索（例: 1980S）
- 列車番号検索後、専用の列車詳細画面へ遷移
- スクリーンショット風の「種別 / M / 両数 / 発着 / 列車番号 / 駅別時刻 / 時計 / 記事」レイアウト
- 1980S は 一宮→津島 のサンプル時刻を収録
- 1800M / 2100I のサンプルも収録
- 未登録列車番号は現在の路線・駅設定からデモ時刻を自動生成
- 既存v3の路線、駅、運行情報デモ、お気に入り、PWA等も維持

注意: すべての列車時刻・位置・運行情報はデモデータです。実際の名鉄運行データではありません。
GitHub PagesではZIPそのものではなく、中身のファイルをリポジトリrootにアップロードしてください。
